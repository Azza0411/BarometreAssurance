Architecture logique

Le flux principal transforme des données brutes en indicateurs consultables. Deux mécanismes s'y greffent : la veille contourne l'extraction pour écrire des alertes directement, et l'assistant conversationnel s'appuie sur les mêmes données déjà validées.

Architecture physique

Quatre conteneurs orchestrés par docker-compose. Le pipeline d'extraction tourne hors des conteneurs et écrit directement en base. Le point à retenir : le chatbot ne lit pas la base MySQL live, il travaille sur une copie SQLite synchronisée.
